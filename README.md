# Practical-work-1-in-Python
## Решение задач с целью изучения основных интернированных и встроенных типов данных, а также их применения
### Версия Python
- Python 3.13.7
### Как запустить программу:
- Скачать файлы
- Открыть и запустить файл main.py
### Примечание
Каждое задание оформлено в виде отдельного файла с собственной логикой решения. Файл main.py выполняет роль точки входа: он импортирует необходимые функции из модулей с заданиями и последовательно их вызывает.
